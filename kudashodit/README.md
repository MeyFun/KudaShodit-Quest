# Квест «КУДА_СХОДИТЬ»

Сайт, где ученики решают задачи по своей странице, а за каждую решённую задачу
открывается кусок готового кода. В конце страницу можно скачать архивом.

| Ученик | Страница | Задач |
|---|---|---|
| Лев Ложников | Вход (`login`) | 12 |
| Самвел Аракелян | Афиша (`afisha`) | 12 |
| Кирилл Зяблов | Регистрация (`register`) | 12 |
| Андрей Плешивых | Профиль (`profile`) | 12 |

Задачи 1–9 — HTML и CSS, 10–12 — JS. Открываются строго по порядку.

## Как запустить
Открыть `index.html` через Live Server (или выложить на GitHub Pages).
Двойным кликом не открывать: превью и проверки работают только через сервер.

## Режим учителя
- `Ctrl + Shift + U` → пароль `3333`.
- **Эталон** — правильное решение текущей задачи.
- **Вставить эталон** — подставляет правильный код в редактор (код ученика заменяется).
  Задача засчитывается только после кнопки «Проверить», как обычно.
- **Пропустить задачу** — засчитывает текущую задачу без проверки и открывает следующую.
- **Сбросить прогресс** — стереть прогресс ученика на этом компьютере.
- Режим живёт до закрытия вкладки или кнопки «Выйти из режима».

Сменить пароль: открыть сайт, F12 → Console → `Quest.hash('новый пароль')`,
полученное число вписать в `teacherHash` в `js/config.js`.

## Прогресс
Хранится в браузере (localStorage) на конкретном компьютере.
На другом компьютере ученик начнёт с нуля — пройденные задачи учитель восстанавливает так:
«Вставить эталон» → «Проверить» → «Следующая задача».

## Если поменялся готовый сайт
Готовый код берётся из папки `KudaShodit`. После изменений в ней:

```
python tools/build.py ../KudaShodit
```

Скрипт заново режет страницы на 12 блоков и пишет `data/code.js`.
Если он пишет «Якорь не найден» — строка-якорь в `tools/build.py` больше не совпадает с файлом.

## Самопроверка задач
Открыть `test.html` через сервер. Для каждой задачи проверяется:
эталон проходит все проверки, а стартовый код — нет. Должно быть «с ошибками 0».

## Файлы
- `index.html`, `css/app.css`, `js/app.js` — сам квест
- `js/engine.js` — превью и проверки
- `js/tasks-*.js` — задачи страниц, `js/tasks-common.js` — общие задачи
- `js/config.js` — ученики и пароль
- `data/code.js` — готовый код страниц (генерируется)
