Команды HTML, CSS и JS

Коротко: команда — что она делает. Здесь всё, что встречается в задачах квестов.

HTML CSS JS

HTML

Части страницы

  • <header>шапка страницы: логотип, меню
  • <nav>меню со ссылками на разделы
  • <main>основное содержимое страницы
  • <section>раздел страницы
  • <article>отдельная карточка: событие, фильм, отзыв
  • <aside>боковая колонка, например с фильтрами
  • <footer>подвал страницы
  • <div>блок-обёртка: группирует элементы, чтобы их оформить

Текст

  • <h1> <h2> <h3>заголовки: h1 — главный, дальше поменьше
  • <p>абзац текста
  • <b>жирный текст
  • <u>подчёркнутый текст
  • <small>мелкий текст, например подпись
  • <br>перенос строки

Ссылки, картинки, списки

  • <a href="...">ссылка; в href — куда она ведёт
  • <a href="#">ссылка, которая пока никуда не ведёт
  • <img src="..." alt="...">картинка: src — путь к файлу, alt — текст вместо картинки
  • <ul> + <li>список с точками, каждый пункт в li
  • <ol> + <li>нумерованный список

Формы и кнопки

  • <form>форма: поля и кнопка отправки
  • <label>подпись к полю; клик по подписи ставит курсор в поле
  • <input>поле ввода в одну строку
  • type="text"обычный текст
  • type="email"почта (браузер проверяет @)
  • type="password"пароль, буквы скрыты точками
  • type="tel"телефон
  • type="number" min="1" max="5"число со стрелками; min и max — границы
  • type="checkbox"галочка
  • name="..."имя поля, по нему JS достаёт значение
  • placeholder="..."серая подсказка внутри пустого поля
  • value="..."значение, которое стоит в поле сразу
  • <textarea rows="4">большое поле для текста; rows — высота в строках
  • readonlyполе только для чтения, менять нельзя
  • <button type="button">кнопка для JS (ничего не отправляет)
  • <button type="submit">кнопка, которая отправляет форму

Другое

  • <dialog>всплывающее окно; с атрибутом open — видно сразу
  • <progress max="..." value="...">полоска прогресса: сколько из скольких
  • class="..."имя элемента для CSS и JS; можно несколько через пробел
  • data-id="..."свои данные для JS (data-type, data-filter, data-level, data-rating...); в JS — element.dataset.id
  • <link rel="stylesheet" href="...">подключить файл CSS (в head)
  • <script src="...">подключить файл JS (в конце body)

CSS

Как писать правила

  • селектор { свойство: значение; }правило: кому и какой стиль
  • pвсе элементы p
  • .cardвсе элементы с классом card
  • .card h3h3 внутри .card
  • .chip.activeэлемент, у которого есть оба класса
  • .a, .bодно правило сразу для нескольких селекторов
  • :hoverстиль при наведении мыши
  • * { box-sizing: border-box; }ширина считается вместе с отступами и рамкой
  • @media (max-width: 768px) { }правила для узких экранов; писать в конце файла

Текст и цвет

  • colorцвет текста
  • backgroundфон; background: none — без фона
  • rgba(0, 0, 0, 0.6)цвет с прозрачностью (последнее число от 0 до 1)
  • font-familyшрифт, через запятую — запасные
  • font-sizeразмер текста
  • font-weightжирность: 400 обычный, 700 жирный, 800 очень жирный
  • line-heightвысота строки, например 1.5
  • text-alignвыравнивание текста: left, center, right
  • text-decoration: noneубрать подчёркивание у ссылки
  • text-transform: uppercaseвсе буквы большие
  • list-style: noneубрать точки у списка

Размеры и отступы

  • width / heightширина / высота
  • width: 100%на всю ширину родителя
  • max-width / min-width / min-heightне шире / не уже / не ниже чем
  • paddingвнутренний отступ: от рамки до содержимого
  • padding: 10px 12px10px сверху и снизу, 12px слева и справа
  • padding-top / padding-bottom / padding-left / padding-rightотступ только с одной стороны
  • marginвнешний отступ: от соседних элементов
  • margin-top / margin-bottomвнешний отступ сверху / снизу
  • margin: 0 autoблок по центру по горизонтали
  • margin: autoпо центру со всех сторон (окно dialog)
  • margin-left: autoприжать элемент вправо (во flex)

Рамки и эффекты

  • border: 1px solid #333рамка: толщина, вид, цвет
  • border: noneбез рамки
  • border-top / border-bottom / border-leftлиния только с одной стороны
  • border-colorтолько цвет рамки
  • border-radiusскругление углов; 50% или 999px — круг / «таблетка»
  • box-shadowтень
  • outline: noneубрать обводку поля при клике
  • cursor: pointerкурсор-рука при наведении
  • resize: verticalбольшое поле можно тянуть только по высоте
  • transition: 0.2sплавная смена стиля, например при наведении
  • transform: translateY(-3px)сдвинуть элемент вверх на 3px
  • ::backdropфон за открытым окном dialog

Display

  • display: blockэлемент на всю строку
  • display: inline-blockв строку с текстом, но можно задать размеры
  • display: noneспрятать элемент
  • display: flexдети в строку (или столбик)
  • display: gridдети по сетке из колонок

Flex

  • flex-direction: columnдети столбиком, а не в строку
  • justify-content: centerпо центру вдоль главной оси
  • justify-content: space-betweenкрая разнесены, между ними равное место
  • justify-content: flex-endприжать к концу
  • align-items: centerпо центру поперёк (по вертикали в строке)
  • align-items: flex-startприжать к началу поперёк (к верху в строке)
  • gapпромежуток между детьми
  • flex-wrap: wrapпереносить детей на новую строку, если не влезают
  • flex: 1ребёнок занимает всё свободное место
  • align-self: flex-startодин ребёнок не растягивается

Grid

  • grid-template-columns: repeat(3, 1fr)3 одинаковые колонки
  • grid-template-columns: 1fr 2fr2 колонки, правая вдвое шире
  • 1frодна доля свободного места
  • align-items: startкарточки в сетке прижаты к верху

Позиция и картинки

  • position: relativeот этого блока считаются координаты детей с absolute
  • position: absoluteэлемент поверх, по координатам top / left / right / bottom
  • position: fixedприбит к окну, не уезжает при прокрутке
  • top / left / right / bottomотступ от края для absolute и fixed
  • object-fit: coverкартинка заполняет блок без искажений (края обрезаются)
  • aspect-ratio: 2 / 3пропорции: ширина к высоте

JS

Найти элементы

  • document.querySelector('.menu')первый элемент по селектору
  • document.querySelectorAll('.card')все элементы по селектору
  • card.querySelector('h3')искать только внутри card
  • element.closest('.card')ближайший родитель с таким селектором
  • element.parentElementродитель элемента

События

  • addEventListener('click', function () { })что сделать при клике
  • addEventListener('input', ...)при каждой букве в поле
  • addEventListener('submit', ...)при отправке формы
  • event.preventDefault()не перезагружать страницу при отправке формы
  • event.targetэлемент, по которому кликнули

Менять элементы

  • classList.add('open')добавить класс
  • classList.remove('open')убрать класс
  • classList.toggle('open')есть класс — убрать, нет — добавить
  • classList.contains('open')есть ли класс (true / false)
  • textContentтекст элемента: прочитать или заменить
  • textContent = ''очистить элемент
  • element.dataset.idзначение атрибута data-id
  • document.createElement('li')создать новый элемент
  • list.append(item)добавить элемент в конец
  • list.children.lengthсколько элементов внутри
  • input.type = 'text'поменять тип поля (например, показать пароль)
  • progress.value / progress.maxзначение и максимум полоски прогресса

Формы и окна

  • form.elements.name.valueчто написано в поле с name="name"
  • .value.trim()значение без пробелов по краям
  • .checkedотмечена ли галочка
  • form.reset()очистить форму
  • dialog.showModal()открыть окно
  • dialog.close()закрыть окно

Переменные и условия

  • const name = ...переменная, которая не меняется
  • let count = 0переменная, которую можно менять
  • count = count + 1увеличить на 1
  • if (...) { } else { }если условие верно — одно, иначе — другое
  • === / !==равно / не равно
  • > < >= <=больше, меньше, больше или равно, меньше или равно
  • &&«и»: верно, если верно оба условия
  • ||«или»: верно, если верно хотя бы одно
  • !«не»: переворачивает условие
  • function showList() { }своя функция; вызвать — showList()
  • returnвыйти из функции (и вернуть значение)

Текст, числа, массивы, объекты

  • 'Привет, ' + nameсклеить строки
  • .toLowerCase() / .toUpperCase()все буквы маленькие / большие
  • .includes('кот')есть ли кусок в строке или элемент в массиве
  • .lengthдлина строки или массива
  • name[0]первая буква строки / первый элемент массива
  • .split(',')разрезать строку в массив по запятой
  • .join(', ')склеить массив в строку
  • Number('5')превратить текст в число
  • Math.round(4.6)округлить
  • Date.now()текущее время числом (удобно для уникального id)
  • const list = []пустой массив
  • list.push(x)добавить в конец массива
  • list.forEach(function (item) { })сделать что-то для каждого элемента
  • list.filter(function (item) { return ...; })новый массив только с подходящими элементами
  • { name: 'Аня', age: 15 }объект: набор «ключ: значение»
  • user.name / data[key]достать значение из объекта

Браузер

  • localStorage.setItem('key', value)сохранить в браузере (останется после перезагрузки)
  • localStorage.getItem('key')прочитать сохранённое (null, если нет)
  • JSON.stringify(data)объект → текст, чтобы сохранить в localStorage
  • JSON.parse(text)текст → объект
  • location.href = '../profile/profile.html'перейти на другую страницу
  • setTimeout(function () { }, 2000)сделать что-то через 2 секунды
  • navigator.clipboard.writeText(text)скопировать текст в буфер обмена
