# Квест «TEAMPLAY»

Сайт, где ученицы решают задачи по своей странице сайта «TeamPlay», а за каждую решённую задачу
открывается кусок готового кода. В конце страницу можно скачать архивом.

| Ученица | Страница | Задач |
|---|---|---|
| Надежда Окольникова | Заявки (`requests`) | 12 |
| Кристина Власова | Отзывы (`reviews`) | 12 |
| Алёна Юрченко | Анкета (`profile`) | 12 |
| Мадина Жумадилова | Дисциплины (`catalog`) | 12 |

Задачи 1–9 — HTML и CSS, 10–12 — JS. Открываются строго по порядку.
В подсказке «Понадобится» показываются все команды задачи, в том числе знакомые по прошлым задачам.

## Как запустить
Выложить папку на GitHub Pages (файл `.nojekyll` уже лежит) или открыть `index.html` через Live Server.
Двойным кликом не открывать: превью и проверки работают только через сервер.

## Режим учителя
- `Ctrl + Shift + U` → пароль `2222`.
- **Эталон** — правильное решение текущей задачи.
- **Вставить эталон** — подставляет правильный код в редактор (код ученицы заменяется).
  Задача засчитывается только после кнопки «Проверить», как обычно.
- **Сбросить прогресс** — стереть прогресс ученицы на этом компьютере.

Сменить пароль: открыть сайт, F12 → Console → `Quest.hash('новый пароль')`,
полученное число вписать в `teacherHash` в `js/config.js`.

## Прогресс
Хранится в браузере (localStorage) на конкретном компьютере.
На другом компьютере ученица начнёт с нуля — пройденные задачи учитель восстанавливает так:
«Вставить эталон» → «Проверить» → «Следующая задача».

## Что получает ученица в конце
Кнопка «Скачать страницу» даёт архив:
```
catalog/  catalog.html, catalog.css, catalog.js   (своя страница)
img/      картинки сайта
```
Четыре архива складываются в одну папку — получается готовый сайт из 4 страниц,
ссылки между страницами вида `../catalog/catalog.html` работают.

## Если поменялся готовый сайт
Готовый код берётся из папки `teammate-site` (лежит рядом с квестом). После изменений в ней:

```
python tools/build.py ../teammate-site
```

Скрипт заново режет страницы на 12 блоков и пишет `data/code.js`.
Если он пишет «Якорь не найден» — строка-якорь в `tools/build.py` больше не совпадает с файлом.
После правок поднять номер версии `?v=N` у файлов в `index.html` и `test.html`, чтобы браузеры взяли новые файлы.

## Самопроверка задач
Открыть `test.html` через сервер. Для каждой задачи проверяется:
эталон проходит все проверки, а стартовый код — нет. Должно быть «с ошибками 0».

## Файлы
- `index.html`, `css/app.css`, `js/app.js` — сам квест
- `js/engine.js` — превью и проверки
- `js/tasks-*.js` — задачи страниц, `js/tasks-common.js` — общие задачи и подсказки
- `js/config.js` — ученицы, шрифты, картинки, пароль
- `site/img/` — картинки сайта для превью и архива
- `data/code.js` — готовый код страниц (генерируется)
