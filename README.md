# Квесты по вёрстке

Сайт: https://meyfun.github.io/KudaShodit-Quest/

Главная страница — переходник: ученик выбирает тему своей команды, потом своё имя и решает задачи.

| Папка | Тема |
|---|---|
| `kudashodit/` | КУДА_СХОДИТЬ |
| `split/` | Сплит |
| `watch/` | Киносфера |
| `teammate/` | TeamPlay |

Каждая папка — отдельный квест со своим README (запуск, режим учителя, пересборка кода).
Режим учителя: `Ctrl + Shift + U` на странице квеста.

Прогресс учеников хранится в браузере по имени ученика, поэтому квесты друг другу не мешают.
